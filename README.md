# Dashboards_python_power-BI
Dashboard de Priorização de Clientes e Análise de Oportunidades
​🚀 Sobre o Projeto
​Este projeto foi desenvolvido com o objetivo de automatizar o fluxo de tratamento de dados e criar uma inteligência visual para a tomada de decisão comercial. A solução conecta fontes de dados relacionais, aplica automações em Python e entrega um painel interativo voltado para a priorização de clientes e identificação de oportunidades de fechamento de contratos.
​🛠️ Tecnologias e Ferramentas Utilizadas
​Python: Linguagem principal para automação e manipulação de dados.
​Pandas: Utilizado para a limpeza, transformação e estruturação das bases de dados em DataFrames.
​SQLAlchemy: Utilizado para a conexão e mapeamento entre o código Python e bancos de dados relacionais.
​Estruturas de Dados do Python: Emprego eficiente de listas e dicionários para organizar, agrupar e preparar os dados brutos antes de alimentar as planilhas e relatórios.
​OneDrive: Armazenamento em nuvem utilizado para centralizar e versionar as planilhas tratadas.
​Google Looker Studio: Plataforma de Business Intelligence utilizada para construir o relatório e o dashboard interativo final.
​⚙️ Como Funciona o Fluxo
​Extração e Conexão: Utilização do SQLAlchemy e Pandas para extrair os dados brutos de forma estruturada.
​Organização e Tratamento: Os dados são limpos e organizados utilizando estruturas nativas do Python (como dicionários e listas) junto com o Pandas, garantindo uma base limpa e sem inconsistências para o Excel.
​Armazenamento em Nuvem: Os arquivos processados são enviados para o OneDrive, servindo como fonte de dados dinâmica e atualizada.
​Visualização Interativa: O Google Looker Studio consome essa base na nuvem para gerar um dashboard executivo interativo.
​📈 Principais Resultados e Indicadores (KPIs)
​O painel final permite que a gestão visualize de forma rápida e intuitiva:
​Priorização de Clientes: Quais empresas possuem maior prioridade com base em critérios operacionais.
​Probabilidade de Fechamento: Identificação das contas com maior chance de conversão e fechamento de novos contratos, direcionando o foco da equipe comercial de forma estratégica.
